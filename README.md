# Mindbreaker

A parlor game that mashes together the three tables people keep asking for:

- **Brick Yard** — breakout with multi-hit bricks and a short stack of balls
- **Trivia Mix** — science, history, sports, movies, food, art, tech, and the rest
- **Letter Play** — guess a word one letter at a time
- **The Circuit** — all three in one run: letter bricks fill the word, quiz bricks pause the board, lives are balls

## Play

```bash
npm install
npm run dev
```

Open the local URL Vite prints (default `http://localhost:5173`).

```bash
npm test        # game-logic tests
npm run build   # typecheck + production bundle
```
